### [Bureaucracy Decoder AI](https://github.com/Anzuniks/REPO-NIMI)
`Python` `FastAPI` `React` `TypeScript` `NLLB` `OCR`

Paikallisesti ajettava sovellus, joka lukee viranomaisasiakirjan (OCR) ja kääntää sen paikallisella NLLB-kielimallilla. Data ei lähde koneelta mihinkään.

- **Oma osuus:** koko sovellus, eli backend, frontend ja mallin integrointi
- **Vaikeinta:** mallin syöte on rajallinen, joten pitkät asiakirjat piti pilkkoa. Kehitin palastelun (*context merging*), joka säilyttää lauseiden ja kappaleiden yhteyden, jotta käännös ei hajoa palojen rajoilla.
